## Technical Curriculum & Assignment Matrix

| Module Directory | Topic Domain | Key Concepts Implemented |
|:---|:---|:---|
| **`Assignments/`** | Core Language & Logic | Loops, conditional recursion, string transformations, mathematical sequences (Fibonacci, primes, matrix algebra) |
| **`python_tutorial/`** | Python Fundamentals | Object-Oriented Programming (OOP), file I/O, exception hierarchies, dictionary and set comprehensions |
| **`templates/`** | Reusable Engineering Templates| Command-line arguments (`argparse`), logging configs, subprocess orchestration |

## Running Scripts

Run any script using the native Python interpreter:

```bash
python Assignments/Assignment_1.py
```
