# Linux & Systems Project Template

Standard template for POSIX system software, kernel modules, device drivers, and system daemons.

## Project Structure
- `source_code/`: System source (`src/`) and C headers (`include/`).
- `architecture/`: Process lifecycle, IPC flow diagrams, and kernel/userspace boundary specifications.
- `documentation/`: System call interfaces, permission models, and failure modes.
- `whitepaper/`: System architecture papers and benchmarks.
- `tests/`: Automated test harnesses, Valgrind memory leak checks, and stress tests.
- `scripts/`: Compilation, installation, and module loading/unloading scripts.
